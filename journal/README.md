# Journal — daily evidence log

Every session ends with an entry: `journal/YYYY-MM-DD.md`. **No journal = session didn't count (Rule 7).**

## Entry format

```markdown
# 2026-08-10 — Day 0

## What I learned
- ...

## What I ran (real commands + output)
```bash
$ whoami
```

## What broke & how I fixed it
- ...

## Questions I still have
- ... (→ goes to question-bank / Anki / NotebookLM)
```

## Evidence rules
- Paste REAL output — no paraphrasing, no "it worked".
- Screenshots go to `evidence/` and get linked here.
- Lab resources destroyed? State it here (Rule 6).
